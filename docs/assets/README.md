# Screenshot placeholders

The files in this directory are intentionally lightweight placeholder SVGs for the public beta release pass.

Expected real capture flow:

1. Run `npm run demo`
2. Open the relevant page at `http://localhost:3000`
3. Capture a desktop-width screenshot with demo data loaded
4. Replace the matching placeholder file while keeping the same filename if possible

## Placeholder mapping

- `dashboard-first-run-placeholder.svg`: dashboard with first-run onboarding cards visible
- `sources-placeholder.svg`: sources page with at least one demo-backed connector visible
- `review-queue-placeholder.svg`: review queue with pending candidates
- `export-page-placeholder.svg`: export page with available formats visible
- `extension-setup-placeholder.svg`: extension setup flow or side panel configuration
