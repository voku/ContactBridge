# Screenshot Capture Guide

Use real screenshots only when they are ready for release documentation. Until then, keep the current SVG placeholders.

## Required browser size

- Capture at desktop width: `1440x900`
- Use the local demo flow so screenshots show fixture data instead of real accounts

## Pages to capture

- Dashboard first-run checklist
- Sources page
- Review queue
- Export page
- Extension setup / side panel hub configuration

## Files to replace

- `docs/assets/dashboard-first-run-placeholder.svg`
- `docs/assets/sources-placeholder.svg`
- `docs/assets/review-queue-placeholder.svg`
- `docs/assets/export-page-placeholder.svg`
- `docs/assets/extension-setup-placeholder.svg`

Keep the same filenames when replacing placeholders so README links stay valid.

## Privacy and safety

- Do not show real tokens, API keys, emails, or private contacts
- Do not capture personal browser profiles with unrelated tabs or extensions visible
- Do not add large binary screenshots in this PR unless the final assets are already approved
